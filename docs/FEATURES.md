# Features

Klencod Web is an Android environment for working with web development projects.

## Visual Inspector

Use the visual preview to select visible elements on a web page and adjust CSS properties through the visual editing workflow.

## Code Editing

Edit the files that make up your web projects, with syntax highlighting and code-completion support for supported languages and formats.

## Project Management

Create and organize projects, manage files and folders, and import or export project archives.

## Live Preview

Preview web pages while working on the project.

## Web-to-APK Builder

Package supported HTML, CSS, and JavaScript projects as standalone Android APKs. Configure the app name, icon, splash screen, and Android permissions before generating the APK.

## Additional Tools

- Multiple editor tabs
- Search and replace
- Multiple editor themes
- Web element inspection and CSS adjustments

Feature availability and language assistance can vary by file type and editor capability.
