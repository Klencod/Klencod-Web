# Installation

## Download from GitHub

1. Open the [Releases](../../releases) page.
2. Select the version you want.
3. Download the APK asset attached to that release.
4. Open the downloaded APK on your Android device.
5. If Android asks for permission to install apps from that source, review the prompt and allow it if you trust the file.
6. Continue with the Android installation flow.

## Choosing a Version

For most users, the latest stable release is the recommended choice. Read the release notes before installing an update.

## Installation Notes

- Download APK files only from release sources you trust.
- Android may display a warning when installing an app outside the Play Store.
- Availability of features may differ between versions.
