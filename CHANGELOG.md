# Changelog

All notable changes to Klencod Web are documented here. For full details and APK downloads, see the [GitHub Releases](../../releases) page.

## [1.2.0]

- Added the ability to package supported HTML, CSS, and JavaScript projects as Android APKs.
- Added APK customization options for the application name, icon, splash screen, and Android permissions.
- Expanded editor language and file-format support with MDX, JSON5, Vue, Svelte, Astro, Pug, Handlebars, GraphQL, and Dockerfile support.
- Improved syntax highlighting and code completion.
- Added further editor themes and usability improvements.

## [1.0.0]

- First official release of Klencod Web.
- Introduced web project editing and management tools.
- Added live web preview.
- Introduced Visual Inspector for selecting page elements and adjusting CSS visually.
- Added search and replace, multiple tabs, and editor themes.
