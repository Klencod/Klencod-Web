# Contributing

Thank you for your interest in improving Klencod Web.

## Reporting Bugs

Please open an issue and include:

- The Klencod Web version
- Your Android version and device model
- A clear description of the problem
- Steps to reproduce it
- Screenshots or logs, if available

## Suggesting Features

Open an issue describing the proposed feature, the problem it solves, and an example of how it could work.

## Before Submitting

Please search existing issues to avoid duplicates and keep reports focused on one problem or suggestion.

This repository currently serves as the official project information and release archive. Do not assume that source-code contributions are accepted unless a contribution workflow is explicitly announced.
